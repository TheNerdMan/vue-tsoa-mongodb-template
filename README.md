# Vue TSOA MongoDB Template

A template for building web applications with Vue.js frontend, TSOA-based Node.js backend, and MongoDB database.

This template includes:
- User authentication and signup functionality
- Vue 3 frontend with TypeScript support
- TSOA-based Express.js backend API
- MongoDB integration
- Docker development environment

## Developer setup
```bash
git clone https://github.com/TheNerdMan/vue-tsoa-mongodb-template.git
```

```bash
cd vue-tsoa-mongodb-template
```

```bash
docker-compose -f etc/docker-compose.yml up --build -d
```

See [the backend README](./backend/README.md) and [the frontend README](./frontend/README.md) for more information on getting each env set up
